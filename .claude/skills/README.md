# APIMatic PayPal Context Plugin skills (TypeScript)

These nine `typescript-*` skills are APIMatic's PayPal Context Plugin, copied unchanged from
https://github.com/context-plugins/plugin-marketplace/tree/main/plugins/paypal/skills/typescript
(plugin version 0.4.1, MIT license, see `APIMATIC-LICENSE.txt`).

They were installed by copying the skill folders because the `npx skills add` installer was not
allowed to run in the build sandbox; the brief's fallback (clone the marketplace and read
`plugins/paypal`) was used instead. How they shaped this build is described in the README under
"Sponsor tools" and in `paypal-plan.md`.
